## Confirmed or source-visible parameters

- User manual PDF metadata: 28 pages, created 2011-09-26. Installation PDF metadata: 2 pages, modified 2009-10-05.
- Manual p. 7 identifies the control panel, oven-function control knob, electronic programmer, temperature control knob, temperature lamp/indicator, oven lamp, core-temperature sensor socket, fan, rear wall heating element, bottom heat, removable shelf supports, and 5 shelf positions.
- Manual p. 8 lists included accessories: wire shelf, baking tray, and core temperature sensor.
- Manual p. 9 says the appliance is activated by turning the oven-function knob and temperature knob; the control knob presses out before use.
- Manual pp. 9-10 list oven functions: Light, True Fan Cooking, Pizza Setting, Conventional Cooking, Bottom Heat, Defrost, Grilling, Fast Grilling, and Turbo Grilling.
- Manual p. 10 identifies the electronic programmer controls: minute minder function indicator, core temperature sensor indicator, time display, time set mode indicator, plus button, and minus button. Minute minder maximum is 2 hours 30 minutes.
- Manual p. 11 says the core temperature sensor can be set from 30 C to 99 C.
- Manual p. 12 identifies an automatic cooling fan and a mechanical door lock.
- Manual pp. 13-22 provide cooking tables, including True Fan Cooking on up to 3 levels, pizza setting table, defrosting table, drying table, and core-temperature table.
- Manual p. 22 gives drying guidance for fruit at 60-70 C and core temperatures including beef rare 45-50 C, beef medium 60-65 C, beef well done 70-75 C, pork shoulder/ham/neck 80-82 C, and salmon/trout 65-70 C.
- Manual p. 26 gives technical data: voltage 220-240 V and frequency 50 Hz.
- Installation PDF p. 1 says the electrical installation must allow all-pole isolation from mains with at least 3 mm contact separation and that the built-in unit must meet DIN 68930 stability requirements.
- Installation drawing p. 1 shows the appliance body dimensions as 594 x 594 x 567 mm, built-in depth 550 mm minimum, cabinet width 560 mm minimum, and 600 mm cabinet height.

## Functions and controls visible from source set

- The exact model has rotary oven-function and temperature controls plus an electronic programmer/clock.
- The exact model has no numbered programs; recipes should name the dial function instead of inventing program numbers.
- Representative same-family AEG Competence control images show a right temperature dial marked from 50 C up to 275 C; the local manual does not print the full dial range as text.
