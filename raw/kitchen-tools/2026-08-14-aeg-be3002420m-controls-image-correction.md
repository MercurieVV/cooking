# AEG BE3002420M "controls-representative" image correction

> Source: Recipe-card review (user), verified by opening the file
> Collected: 2026-08-14
> Published: 2026-08-14

## What was wrong

`images/aeg-be3002420m-controls-representative.jpg` was logged in
`ACQUISITION-LOG.md` (2026-08-13 entry) as a "representative control-panel
product image" sourced from a Hausdorf listing for the *BE3013421M* oven:
`https://www.hausdorf.ru/upload/thumb/catdm/iblock/632/dukhovoy-shkaf-aeg-be3013421m.jpg`.

Opening the file shows it is not a close-up of the control panel — it is a
full product photo of that other oven (BE3013421M), door open, showing the
entire cavity, racks and interior, with the dial/display strip visible only
as the top ~15% of the frame. Used as a tool `part` next to
`images/aeg-be3002420m-product-representative.jpg` (also a full-oven photo,
of yet another sibling model, BE3003021M), a generated recipe card showed
what read as two separate ovens.

## Correction

No genuine close-up photo of the BE3002420M (or a same-family sibling)
control panel/dial strip has been found. A live web search on 2026-08-14
for "AEG BE3002420M control panel close up photo" returned only generic
spare-part listings for unrelated control-panel replacement parts (e.g.
AEG spare part 5615043030), not a photo of this oven's actual panel — not
usable as a stand-in without misrepresenting the owned unit's controls.

Until a real close-up is sourced: do not use
`aeg-be3002420m-controls-representative.jpg` as a tool `part` image
alongside `aeg-be3002420m-product-representative.jpg` — both are full-oven
photos and read as duplicate appliances. The oven's dial/display layout
(two rotary dials either side of an LED time display) can still be
described in `program`/`settings` text; it should not be shown as a second
photo.
