# Cooking

Personal cooking knowledge base: raw source material (manuals, notes) under `raw/`, compiled into recipe and kitchen-equipment articles under `wiki/`. Recipes are generated as appliance-specific step-by-step plans — a printable photo-card PDF and a VR-optimized interactive HTML page — tailored to the ovens, mixers, and other equipment actually owned.
